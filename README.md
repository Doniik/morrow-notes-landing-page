# Morrow — Notes Landing Page

A responsive Week 1 landing page for a note-taking website, built with Next.js App Router, React, TypeScript, CSS, and Lucide icons.

## Run locally

1. Install Node.js (LTS) if it is not already installed.
2. Open this folder in VS Code.
3. In Terminal → New Terminal, run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000.

## Included

- Hero section with CTA and note-app mockup
- Feature cards
- Brand statement section
- Final CTA
- Footer and navigation
- Responsive mobile styles
